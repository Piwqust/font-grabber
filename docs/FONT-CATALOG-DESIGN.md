# Fount: каталог шрифтов вместо редактора

Дата: 2026-09-05. Этот проход заменяет направление предыдущего UX-AUDIT.md по просьбе пользователя: сетка и удобное скачивание; редактирование метаданных временно исключено. Старое требование .impeccable.md о списке без карточек больше не определяет эту версию.

## Изученные референсы

Все три сайта открыты в настоящем браузере; изображения сохранены в output/reference-grid.

- [Fontshare](https://www.fontshare.com/?view=grid): переключение Grid view проверено. Взяты крупные типографические образцы, общий текст/размер и сравнение рядом. Не перенесены многочисленные фильтры, для которых наш скан не даёт данных. Снимок: fontshare-grid.png.
- [Google Fonts](https://fonts.google.com/): просмотр каталога, общий preview и выбранные семейства. Взяты единые настройки образца и отдельный просмотр выбранного. Снимок: google-fonts.png.
- [Fontesk](https://fontesk.com/): визуальный каталог с выразительными шрифтовыми образцами. Взята идея типографической витрины, но наши образцы остаются настоящим текстом из загруженного шрифта. Снимок: fontesk.png.

## Реализация

- core/src/web/index.html: компактный ввод адреса; расширенные параметры по раскрытию; поиск, общий образец и размер; All fonts / Selected; нет полей имени, PostScript, family или filename.
- core/src/web/app.js: оригинальные названия из результата скана, без клиентских подстановок и без names в запросах скачивания. Одиночное скачивание отправляет один ID, групповое — отмеченные ID. Клик Download не меняет текущий выбор. Серверная конвертация и существующая обработка названий на сервере не менялись.
- core/src/web/style.css: сетка из 3 колонок на 1280 px, 2 на промежуточных экранах, 1 на телефоне. Явное выделение карточки, видимые кнопки скачивания, панель выбранного. Страница использует существующие локальные Geist, Newsreader и Plex Mono.
- Кнопка Try this page действительно сканирует текущую страницу в режиме Static. Начальные образцы подписаны названиями реально используемых здесь шрифтов; это не поддельные результаты чужого сайта.
- Предыдущая версия трёх файлов сохранена в output/before-grid. Расширение браузера и серверный API не редактировались. Новых зависимостей приложения нет.

## Проверки

- cargo build --manifest-path core/Cargo.toml --offline — успешно; два прежних предупреждения dead_code.
- node --check core/src/web/app.js — успешно.
- Prettier и git diff --check — успешно.
- output/reference-grid/check-grid.js — 27 проверок WebKit прошли: реальный скан 5 шрифтов, отсутствие редактора, 3 колонки, загрузка превью, мышь/Space, вкладка выбранного, отмена выбора, общий текст/размер, восстановление после пустого поиска, одиночная и групповая загрузка, отсутствие names в обоих запросах, ширины 320/375/768/1280.
- Архив single-font.zip открыт через .NET: один файл Geist-400.otf. selected-fonts.zip: два файла Geist-400.otf и Geist-600.otf. Это настоящие запросы к локальному Rust API, без подмены успешных ответов.
- output/reference-grid/check-grid-edge.js — 11 проверок с явно искусственными ответами: 81 результат/пагинация, длинные названия и образцы, выбор по фильтру, пустая выборка, блокировка скачивания при скане, сохранение выбора при ошибке, пустой ZIP-ответ и нулевой результат.
- Первая версия теста использовала uncheck() по динамическому первому элементу вкладки Selected: после удаления карточки Playwright пытался снять выбор со следующей. Проверка исправлена на один click() и проверку числа оставшихся карточек.

Снимки результата: implemented-home.png, result-desktop.png, result-mobile.png в output/reference-grid.

## Пределы проверки

WebKit на Windows не равен физическому iPhone. В этом проходе не проверялись hosted-развёртывание и сканирование произвольных внешних сайтов. Предыдущий аудит выявил пустой HTTP 204 при загрузке через Chrome, тогда как WebKit и прямой запрос возвращали архив; системный перехват загрузок в этом проходе не исправлялся. Защита от пустого архива сохранена.
